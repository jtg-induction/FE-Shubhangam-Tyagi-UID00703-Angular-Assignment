# Blog99

A feature-rich blogging platform built with Angular 17, demonstrating mastery of components, routing, and API integration

## Project Setup

### Prerequisites

- Node.js 20

### Installation

1. **Clone the repository**

   ```bash
   git clone <repository-url>
   cd FE-Shubhangam-Tyagi-UID00703-Angular-Assignment
   ```

2. **Install dependencies**

   ```bash
   npm i
   ```

3. **Start the server**
   ```bash
   # Development mode
    ng serve
   ```

The server will start on `http://localhost:4200`
